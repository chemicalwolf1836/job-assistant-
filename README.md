# AI Job Application Assistant

A Python AI tool that turns your CV (PDF) and a pasted job description into five
tailored application assets — a cover letter, CV suggestions, a skills-gap
analysis, interview questions, and a salary estimate — streamed live through a
Gradio interface.

▶️ **Live version (reimplemented, in-browser) on my portfolio:**
https://batmagnai-ganbaatar-portfolio.vercel.app/job-assistant-app.html

## Stack

- **Python** — application layer
- **Gradio** — chat UI with streaming output
- **Groq API** — Llama 3.3 70B for generation
- **pdfplumber** — PDF CV text extraction
- **Markdown export** — download any output as a `.md` file
